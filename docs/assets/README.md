# Product brand assets

Original SVG artwork created for this repository. **These are brand illustrations, not screenshots or evidence of a running application.** No external art, scripts or network resources are embedded.

| Asset | Purpose | Raster size |
| --- | --- | --- |
| product-banner.svg | README hero | SVG source |
| features.svg | Product feature illustration | SVG source |
| social-preview.svg / .png | Social / Open Graph preview | 1280×640 PNG |
| release-visual.svg / .png | Release illustration | 1200×460 PNG |
| product-mark.svg / .png | Documentation mark | 256×256 PNG |

The PNGs are rendered from the SVG sources by headless Chromium at device scale1. Dimensions, nonzero sizes and nonblank image statistics were checked with Pillow. No product UI screenshot was generated or modified by this render.

Social-preview upload to GitHub is **NOT APPLIED**: the metadata operation currently lacks access (403). The raster file is provided for later upload; its presence does not mean repository settings changed. The documentation mark does not replace the packaged executable icon.
