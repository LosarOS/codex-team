# Установка приложения в Windows

Пошаговая инструкция: [Установка Codex Team](../INSTALL_WINDOWS.md).

Обычная установка использует `%LOCALAPPDATA%\Programs\CodexTeam` для программы и `%LOCALAPPDATA%\CodexTeam` для истории и настроек. Переносимый ZIP использует папку `data` рядом с программой через маркер `portable.json`. Переменная `CODEX_TEAM_DATA_ROOT`, если задана, переопределяет оба варианта.

Python, официальный Codex и переносимый Git входят в комплект. Системный `PATH` не изменяется. Для окна нужен WebView2: при его отсутствии русский мастер установки предлагает официальный загрузчик Microsoft с явным подтверждением. Тихая установка требует готового Runtime.

Первый запуск: откройте программу через ярлык, выполните официальный вход ChatGPT / Codex, добавьте Git-проект и подготовьте задачу. Основное подключение не требует отдельного API-ключа. OpenAI API — необязательный вариант с отдельной оплатой.

Проверка качества настраивается отдельно: нужен локальный Docker с Linux-контейнерами и доверенный образ. Docker, образы и зависимости рабочих проектов автоматически не устанавливаются.

Обновление выполняется при закрытом приложении. Удаление программы сохраняет историю, настройки, проекты и авторизацию. Нативную приёмку Windows и проверку переносимой версии следует выполнять на фактически скачанном выпуске; результаты Linux-проверок её не заменяют.
