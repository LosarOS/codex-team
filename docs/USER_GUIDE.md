# User guide

Выберите clean Git root, task и режим. После START просматривайте stages, Action Center, native commands и diff. DONE относится к выбранному режиму: Plan не означает coding, Audit не означает внесение fixes.

Pause — stage boundary; Stop — cancel; Steer — current/next roles; Queue — next stage; Resume — сохранённый checkpoint. Не редактируйте worktree вручную перед Resume. Review/merge/push остаются за пользователем.

Tray поддерживает open/pause/logs/quit. Active close предлагает tray/stop/cancel. Recovery banner и History позволяют продолжить interrupted run. Diagnostics ZIP создаётся через Save dialog; проверьте его перед передачей.
