# Codex Team 1.0.0-rc6 — быстрее работать, сложнее потерять результат

## Что нового

- **Поиск и команды — Ctrl+K.** Переход к любому разделу, поиск подключённого проекта и загруженного запуска. Стрелки, Enter и Escape работают с клавиатуры; поиск выполняется локально и не расходует токены.
- **Сохраняемый черновик задачи.** Текст, проект, режим и лимиты сохраняются в локальной SQLite. После перезапуска можно восстановить черновик, заменить его текущим текстом или удалить. Конфликты между окнами не перезаписывают ввод автоматически.
- **Восстановление связи.** Повторные запросы замедляются при недоступности сервера, скрытое окно прекращает опрос, а кнопка повторного подключения доступна сразу. Ошибка отдельных данных больше не означает, что всё приложение отключено.

## Исправления

- Budget Guardian теперь сохраняет уже измеренный расход даже при ошибке, прерывании или разрыве соединения агента.
- Новая сессия после смены уровня доступа больше не наследует базу токенов предыдущей сессии. Продолжение той же сессии не считает токены повторно.
- Проверка состояния серверной части действительно проверяет базу данных и наличие Git, вместо безусловного успешного ответа.
- Первый ответ сервера и обновление настроек не затирают уже введённые параметры задачи.

## Безопасность и совместимость

Черновик — локальный текстовый буфер, не запрос на запуск. Он не отправляется модели автоматически. Уровень доступа, согласие на полный доступ, провайдер и API-ключи в черновик не входят. Перед запуском действуют обычные проверки разрешений.

Сохранён выбор языка **Русский / English**, а также Obsidian Violet, Neon Blue, Emerald Tech, Crimson Night и все прежние темы. Добавлена одна совместимая таблица SQLite; история, проекты, контрольные точки и настройки сохраняются.

## Установка и обновление

Скачайте `CodexTeam-Setup-x64.zip`, распакуйте и запустите установщик. Для переносимого запуска распакуйте **весь** `CodexTeam-Portable-x64.zip`.

Для обновления существующей версии закройте приложение и запустите `Обновить.cmd` из его папки. Пользовательские данные удалять не нужно. GitHub «Source code» не является готовой сборкой Windows.

## Проверки и ограничения

Доказательства проверки и SHA256 публикуются вместе с установщиком. Реальные скриншоты используют обозначенные тестовые данные; модельные вызовы для проверки интерфейса не выполняются.

Нативная интерактивная приёмка WebView2, настоящий Windows DPI и вход в аккаунт остаются отдельной ручной проверкой. Приложение не подписано сертификатом. Это предварительная версия.
