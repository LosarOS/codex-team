# Codex Team 1.0.0-rc10 — Очередь миссий

## Несколько задач — один управляемый запуск

Подготовьте задачи на странице «Обзор» и нажмите **«В очередь»**. Для каждого задания сохраняются полный текст, проект, режим, набор агентов, доступ и числовые лимиты. Черновик остаётся в форме. Добавление не запускает модель.

На новой странице **«Очередь миссий»** можно посмотреть задания, изменить порядок, пропустить ненужное и отдельно подтвердить запуск очереди. Задачи выполняются последовательно через существующий движок Codex Team. Следующая начинается только после успешного завершения предыдущей.

## Контроль и безопасность

- Ошибка, пауза, нехватка лимита, необходимость входа или решения пользователя останавливают очередь. Откройте связанный запуск, завершите его или явно пропустите задание.
- **«После текущей задачи»** запрещает запуск следующей, сохраняя работу текущей. Для немедленной паузы/остановки используются прежние действия на странице запуска.
- Каждое задание получает независимую изолированную копию Git. Очередь не переносит изменения между заданиями и не объединяет их автоматически. Это пакет независимых задач, а не цепочка изменений одной ветки.
- Полный доступ требует отдельного подтверждения для каждого задания. Обычные разрешения, проверка качества, бюджет и Git-изоляция продолжают действовать.
- Эффективные лимиты фиксируются при добавлении, включая применимые настройки бюджета проекта. Последующие изменения политики не повышают бюджет сохранённого задания.
- После перезапуска приложения очередь сохранена и не запускается автоматически. Прерванные задания требуют проверки пользователя.
- Повторный запрос добавления с тем же идентификатором не создаёт дубль. История очереди остаётся в SQLite; интерфейс показывает активные и последние 100 завершённых записей.

## Интерфейс

Отдельная страница, карточки состояния, полный текст постановки, доступ и лимиты, ссылки на запуски, явные состояния ошибок и восстановления связи. Поддержаны **Русский / English** и все существующие цветовые темы, включая **Obsidian Violet**, **Neon Blue**, **Emerald Tech**, **Crimson Night** и Light. Проверки используют обозначенные тестовые данные; выдуманных процентов выполнения и расходов нет.

## Обновление

Закройте приложение и запустите **«Обновить.cmd»**, либо скачайте установочный ZIP. Portable распакуйте целиком. Существующая история и настройки сохраняются; добавляется отдельная таблица очереди.

## Проверки и ограничения

Проверяются Python, frontend, браузер, настоящая Windows-сборка и установка с сохранением очереди после restart. Модельные вызовы для QA не выполняются. Интерактивный WebView2, DPI и живой запуск Codex остаются ручной приёмкой. Бинарники unsigned; это предварительный выпуск.
