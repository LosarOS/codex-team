# Codex Team 1.0.0-rc12 — plan, context and control

Release candidate notes. [Русский](https://github.com/LosarOS/codex-team/blob/master/docs/releases/v1.0.0-rc12.md).

## New capabilities

- Edit and save a Task Architect work plan with acceptance criteria, files and dependencies. Validation detects cycles and stale specification versions. An explicit reviewed root-step handoff fills the existing composer; it never starts a mission or executes a dependency graph.
- Inspect source freshness for project knowledge. Stale, unbound or malformed records remain available for review but are excluded from bounded context previews. Repository content stays untrusted data.
- Read actual mission events in a deduplicated timeline and see actionable blocker explanations. No invented progress percentages or automatic retries.
- Export the selected usage page with project/UTC-day filters. Unknown cost, token and account quota values remain unknown. Browser export saves the preview; desktop export refreshes the same filters through the guarded backend and opens native Save. Native cancellation never falls back to a hidden Blob download.

## Reliability and security

Startup now begins with a neutral checking state. Local backend health settles independently of SDK account discovery; unknown provider state stays unverified and never becomes a fabricated login requirement. Late health responses cannot overwrite newer readiness, and execution guards require a fresh known provider result.

Fixed malformed usage/source-binding exceptions. Existing explicit start, frozen budgets, isolated worktrees, permission controls, drafts/history and no-automatic-merge rules remain. Updated vulnerable pinned opentelemetry-api/setuptools; the retained audit reports its exact40-pin coverage rather than claiming every bundled component is secure.

## Installation and update

Use CodexTeam-Setup-x64.exe or extract the complete CodexTeam-Portable-x64.zip. WebView2 is required. Stop missions, Quit and back up the entire data directory before updating. [User guide](https://github.com/LosarOS/codex-team/blob/master/docs/RC12-GUIDE-EN.md).

Actual portable WebView2 has opened its task form and native Save, written a JSON report and quit with native exit0 and no forced cleanup. ## Known limitations

Unsigned binaries may trigger SmartScreen. New plans are not an automatic dependent mission queue. Usage export covers the current page, not an internal account quota. Same-version installer repair is not proof of every historical-version upgrade. Original artifact and evidence sources are retained; publication is not claimed until assets are public and re-downloaded bytes pass verification.
