      ВНЕШНИЙ ВИД
      Оформление применяется сразу и сохраняется локально, включая работу без связи с сервером.
      

      Разрешения и уведомления
      Официальные разрешения Codex определяют доступную область действий. «Запрашивать» показывает поддерживаемые запросы; «Запрещать» отклоняет запросы данной категории.
      Локальные уведомления
      Лимиты и модели по умолчанию
      Применяются к новым запускам, если у роли не выбрана собственная модель.
      Приложение
      ПРИЛОЖЕНИЕ
      Модели по умолчанию для ролей
      Приоритет для каждого поля: индивидуальная настройка агента → общее значение роли → общая настройка приложения → значение Codex. Пустое поле использует следующий уровень. Доступные модели поступают из официального списка.
      О приложении
      Codex Team
      Локальный центр управления в Windows на базе официального Codex SDK. Независимые агенты, Git-изоляция, история и проверка результата.
      Данные задач остаются на компьютере. Запросы к выбранному исполнителю содержат контекст проекта. Телеметрия приложения отсутствует.
      Документация
      Руководство установки: docs/DESKTOP_INSTALL.md. Подробности среды выполнения и безопасности: docs/DESKTOP_ARCHITECTURE.md. Эти документы входят в исходный репозиторий приложения.
