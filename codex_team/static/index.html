      Официальные разрешения Codex определяют доступный scope. «Запрашивать» показывает поддерживаемые запросы; «Запрещать» отклоняет запросы данной категории.

      Лимиты и модели по умолчанию
      Применяются к новым запускам, если у роли не выбрана собственная модель.
      Приложение
      DESKTOP
      Модели по умолчанию для ролей
      Приоритет для каждого поля: индивидуальная настройка агента → общее значение роли → общая настройка приложения → значение Codex. Пустое поле использует следующий уровень. Доступные модели поступают из официального списка.
      О приложении
      Codex Team
      Локальный Windows Control Center для официального Codex SDK. Независимые агенты, Git-изоляция, история и проверка результата.
      Данные задач остаются на компьютере. Запросы к AI provider содержат контекст выбранного проекта. Телеметрия приложения отсутствует.
      Документация
      Руководство установки: docs/DESKTOP_INSTALL.md. Подробности runtime и безопасности: docs/DESKTOP_ARCHITECTURE.md. Эти документы входят в исходный репозиторий приложения.
