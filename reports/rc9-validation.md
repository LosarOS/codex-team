# Codex Team rc9 — безопасное повторение задач и владение запросами

База master: `958c2f9ed42fa18bf315cd64a00d2cf1646a3cee` (rc8). Ветка: `codex/run-replay-reliability-rc9`.

## Реализация

Кнопка «Повторить задачу» встроена в подробности существующего запуска. `GET /api/runs/{id}/replay` читает полную сохранённую постановку, предпочитает original_workspace и возвращает только восемь полей существующего DraftData: текст, проект, режим, набор, специалисты и три числовых лимита. Нет запуска агента, resume, файловых операций или изменения исходной истории. Некорректная/слишком длинная постановка блокируется вместо обрезания; отсутствующие параметры получают значения редактора с явными предупреждениями.

UI подтверждает замену формы, проверяет её снимок и ID выбранного запуска до и после запросов/подтверждения, блокирует повторные действия. Новый read-only getter TaskDraft.canReplace запрещает замену во время первоначальной загрузки, операции или нерешённого конфликта/сохранённого черновика. Применение устанавливает standard, isolated=true, auto_commit=false и параллельный лимит 2. Старые сессии, provider/model overrides, токеновый бюджет запуска и согласие на full-access не копируются. Пользователь отдельно проверяет настройки и запускает задачу. Обычный автосохранённый черновик остаётся механизмом сохранения редактора.

Показана подсказка об источнике и безопасных настройках, её скрытие не очищает текст. При применении другого черновика/шаблона подсказка скрывается. RU/EN и semantic themes сохраняются, новых зависимостей и миграций нет.

## Подтверждённые дефекты

| Приоритет | Воспроизведение | Исправление / доказательство |
|---|---|---|
| P1 | Старый запрос diff стартует во время выбора B под тем же поколением; после открытия B его ответ подменяет новые изменения/снимает busy | Guard ID+generation+identity запроса; старые успех/404/500, повторный выбор того же ID и новые загрузки проверены deferred requests |
| P1 | Старый запрос событий очищает указатель нового запроса | Guard владельца Promise, накопленные события сохранены; тест отдельно падает при удалении identity-guard |
| P1 | Ручной refresh ожидает A под поколением выбора B; после открытия B его ответ возвращает A | Дополнительная проверка текущего selected ID перед записью; исходный тест воспроизвёл возврат A |
| P1 | Аналогичная гонка polling после await действий | Тот же guard выбранного ID; контролируемая последовательность запросов до/после |
| P2 | SQLite length(note) обрывается на нулевом символе: непустая локальная заметка не отмечается в истории | Проверка note<>'' без изменения текста; HTTP regression падал до исправления |
| P2 | DraftData/RunRequest допускают 30+ секунд, а min=1 и implicit integer step формы блокировали такие сохранённые параметры | min=0.5 минут, step=any; браузер проверяет 31 секунду, validity и точное сохранение в черновик |

Не менялись разрешения существующих запусков, engine lifecycle, checkpoints, Codex SDK и Git worktrees. Новые задачи проходят прежний preflight и отдельное подтверждение полного доступа.

## Безопасность

Новый API read-only и использует прежние Host/origin-защиты. Текст задачи остаётся локальным редактором и может содержать сведения пользователя; автоматически отправлять его модели не требуется. Восстановление разрешений/ключей/старых threads запрещено allowlist и отдельным сбросом UI. Код не выбирает исполняемые команды и не обращается к рабочему каталогу. Подтверждение защищено от устаревшего ответа и изменения текущей формы. Реальные inference-запросы для QA не выполнялись.

## Windows-приёмка

1. Обновить Setup/Portable целиком, проверить старую историю, заметки, шаблоны, настройки и язык.
2. Открыть старый запуск → «Повторить задачу». Отменить: текущий ввод сохранён. Подтвердить: полная постановка и исходный проект в форме, отдельный запуск не начался.
3. Проверить standard/изоляцию/выключенный auto-commit. Выбрать нужный доступ заново; полный доступ требует отдельного подтверждения перед запуском.
4. Проверить нерешённый черновик, конфликт двух окон и восстановление после restart. Новый подготовленный текст сохраняется обычным черновиком.
5. На медленной связи переключать A/B, вкладки событий и diff, нажимать обновление. Указание, выбранный запуск, события и diff не должны подменяться поздними ответами.
6. RU/EN, все темы, длинный текст/путь, Tab/Escape, DPI100/125/150/175%. Проверить точный нестандартный лимит времени, если он есть в старой записи.
7. Проверить реальный официальный вход, небольшую задачу, pause/resume/stop, Центр действий, updater и штатное завершение.

Интерактивный WebView2, настоящий DPI и live Codex остаются NOT VERIFIED. Нативная автоматизация не заменяет эту приёмку. Выпуск unsigned/prerelease.
