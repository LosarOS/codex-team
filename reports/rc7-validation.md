# Codex Team rc7 — новые рабочие инструменты и надёжность

База: `59230babf6779f4754321f703f73002d0e4e3afc` (master / rc6). Ветка: `codex/templates-run-comparison-rc7`.

## Реализация

**Шаблоны задач.** Локальная библиотека основной формы: создание из текущего ввода, поиск, редактирование названия/описания без замены постановки, явное обновление снимка из формы, подтверждаемое применение и удаление. Новая аддитивная SQLite-таблица, до 200 записей, metadata-only pagination, Unicode casefold поиск. CAS под `BEGIN IMMEDIATE` защищает от устаревших изменений между окнами. Черновики и шаблоны — разные сущности: черновик сохраняет текущий ввод, шаблон переиспользуется по желанию пользователя.

**Сравнение запусков.** Один read-only endpoint читает две записи Store; UI открывается из истории. Показаны сохранённые настройки и результаты, вызовы, фактическое время, наблюдаемые токены, число файлов и последние результаты ролей. Ничего не исполняется и рабочие каталоги не читаются. Неизвестные показатели — `null` / «Нет данных», измеренный ноль остаётся нулём. Разные проекты, незавершённое выполнение, неполные usage и сокращённая история явно обозначены. Windows-пути сравниваются лексически, включая регистр, без обращения к файловой системе.

Новые API: `/api/task-templates` (GET/POST), `/api/task-templates/{id}` (GET/PUT/DELETE с revision), `/api/run-comparison?left=&right=` (GET). Основной orchestration, permission model и официальный Codex SDK не заменялись.

## Подтверждённые дефекты

| Приоритет | Воспроизведение | Исправление / проверка |
|---|---|---|
| P1 | Сохранённые usage `null`, строковые счётчики или не-dict записи ломали summary API | Нормализация только фактических неотрицательных целых счётчиков; API regression на настоящем `create_app` |
| P2 | `usage=[]` показывалась в списке как 0 токенов, хотя подробный экран знал об отсутствии данных | Nullable totals, отдельные `usage_available` / `usage_complete`; измеренный ноль сохранён; предупреждение в обзоре |
| P2 | Snake-case usage и input+output fallback расходились с бюджетом | Единые наблюдаемые форматы в сводках без повторного подсчёта cumulative totals; сохранённые детали не изменяются |
| P2 | Поиск истории «АВТОРИЗАЦИЯ» не находил «Авторизация» | Unicode casefold-функция на SQLite-соединении только для явного поиска; 4 теста падали до исправления, literal %/_ и pagination сохранены |
| P2 | При QA нового диалога выбор шаблона оставлял фокус на BODY, т.к. поле было disabled во время focus() | Фокус возвращается после снятия busy; реальный Chromium, keyboard/focus regression |
| P2 | В длинных новых диалогах заголовок/закрытие уходили за прокрутку | Закреплённые заголовки и scroll-padding; видимость закрытия проверяется после scroll-bottom |

## Безопасность и данные

В шаблон допускается тот же строгий набор полей, что в черновик. Provider, API keys, уровень доступа, подтверждение полного доступа, auto-commit и isolation отвергаются схемой; применение не выдаёт разрешений. Текст сохраняется буквально в локальном профиле и может содержать чувствительные сведения, введённые пользователем; не следует хранить там секреты без необходимости.

Существующая same-origin/Host/JSON-защита применяется к новым endpoints. Сравнение отдаёт разрешённый набор фактов, не credentials или provider-конфигурацию. UI использует textContent, версии запросов, busy guards и подтверждения. Нет скрытых модельных вызовов, платных сервисов, автоматического push/merge рабочих проектов или нового механизма orchestration.

## Windows-приёмка владельцем

1. Установить Setup / распаковать весь Portable, проверить запуск WebView2 и сохранение старой истории/темы/языка.
2. Создать шаблон из формы, закрыть/открыть приложение; применить, проверить проект, набор и доступ. Убедиться, что агент не стартовал сам.
3. Переименовать без изменения текста; явно обновить из формы; проверить поиск русским верхним регистром и подтверждение удаления. Проверить конфликт двух окон.
4. Открыть историю, выбрать два запуска (включая разные страницы), поменять стороны, обновить и открыть исходный запуск. Проверить «Нет данных» и предупреждения.
5. Прокрутить оба диалога до конца: закрытие доступно; Tab/Escape работают. RU/EN, все темы, DPI 100/125/150/175%, длинные пути и длинные задачи.
6. Проверить официальный вход и небольшую реальную задачу, pause/resume/stop, Action Center. QA Docker — только с доверенным образом и явным подтверждением.
7. Проверить `Обновить.cmd`, tray, уведомления, shutdown/restart. Историю/данные не удалять.

Интерактивный WebView2, настоящий DPI, живой Codex и Docker opt-in в облаке не считаются проверенными. Бинарники без Authenticode. Выпуск остаётся prerelease.
