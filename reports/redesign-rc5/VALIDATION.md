# Codex Team rc5 — дизайн, RU/EN и выпуск

## Область проверки

Исходная ветка: `master` / `1d19465`. Изменения: PR #10, `codex/redesign-i18n-theme-audit-release`.

Визуальный ориентир — предоставленные владельцем тёмные панели с фиолетовым акцентом. Изменены сами поверхности, границы, типографика, иконки, активная навигация и кнопки, а также рабочие панели. Числа и функции из концептов не перенесены как реальные данные.

Все новые интерфейсные ресурсы локальны. Production backend проверяется отдельно от браузерного fixture-сервера. Контент задач, инструкции, имена проектов, исходники и журналы не переводятся автоматически.

## Безопасность и целостность

Сохранены официальный SDK, разрешения, отдельное согласие на полный доступ, ограничения других ролей и режимов Audit/Plan. Локальный API не расширен на внешний интерфейс. CSP не ослаблен. Временный GitHub read token используется только CI smoke-step после упаковки и только для фиксированного API endpoint без redirects; заголовки скачивания не содержат авторизацию. Пользовательский токен обновлятору не требуется. Ресурсы локализации и SVG выдаются по строгому белому списку; произвольные файлы приложения и профиля недоступны.

Не добавлены миграции, удаление пользовательских данных, вызовы удалённого перевода, скачивание Docker-образов или установка зависимостей пользовательского проекта. Новые UI-элементы используют существующие действия и API. Метрики «нет данных» не подменяются нулями. Линии карты показывают принадлежность каталогов проекту, **не** выдуманные зависимости кода.

## Windows smoke checklist владельца

1. Сохранить копию существующего профиля; закрыть приложение. Установить Setup ZIP поверх прежней версии и отдельно распаковать portable в новую папку.
2. Проверить старые проекты, историю, агентов, контрольные точки и настройки. Перезапустить приложение.
3. Открыть все страницы; переключить RU/EN и каждую тему. Проверить длинные пути с кириллицей и формы с несохранённым текстом: отмена смены языка должна сохранить текст.
4. Проверить 1024×768 / 1280×720 / 1366×768 / 1440×900 / 1920×1080 / 2560×1440 и настоящий Windows DPI 100/125/150/175%. Проверить клавиатуру, фокус, модальные окна, прокрутку.
5. Войти через официальный Codex; создать локальный проект и короткую задачу. Проверить уровни доступа, Mission Control, паузу/продолжение/остановку и восстановление после перезапуска.
6. Обновить локальный анализ, выбрать модуль и открыть источник. Сохранить/изменить знание и черновик ТЗ.
7. На тестовом репозитории проверить новую контрольную точку, сравнение и восстановление **в отдельную рабочую копию**; исходные незакоммиченные файлы должны сохраниться.
8. При наличии доверенного локального Docker-образа пройти настройку QA и подтверждённый test run. Проверить FAIL/BLOCKED, а не только PASS.
9. Закрыть приложение, запустить `Обновить.cmd` обычным двойным щелчком (без аргументов), проверить доступность версии; не удалять папку данных. Проверить tray, уведомления и корректное завершение.

Нативный интерактивный WebView2, реальный DPI и live Codex **NOT VERIFIED** в этой среде. Windows CI сборки/установки не заменяет эти действия. Приложение не подписано сертификатом.
