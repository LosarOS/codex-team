# Codex Team 1.0.0-rc6 — проверка улучшений продукта

Исходная база: `4d00bf32a52eff812a0cb7938ede64649f5539f1` (`master`, rc5).
Рабочая ветка: `codex/productivity-resilience-rc6`.

## Что изменилось

- Палитра Ctrl+K: переходы между разделами и поиск по подключённым проектам / загруженным запускам. Локальный поиск без API и модельных вызовов; список явно обозначает границы поиска. Клавиатура, Escape, возврат фокуса, RU/EN, все темы.
- Черновик основной задачи: SQLite, автоматическое сохранение после изменения, явное восстановление и удаление, оптимистическая revision для нескольких окон. Разрешения, полный доступ, провайдер и ключи не сохраняются. Перед запуском пользователь заново проверяет доступ.
- Чтение состояния: один цикл опроса, остановка скрытой вкладки, увеличение интервала при ошибках до 30 секунд, восстановление после подключения, без повтора изменяющих запросов. Ошибка отдельных данных отображается отдельно от полной недоступности.
- Health: реальная проверка SQLite и наличия Git; HTTP 503 при недоступности вместо ложного `ok`.
- Установочный smoke расширен проверкой сохранённого черновика и языка/темы после реального перезапуска установленного backend.

## Безопасность и данные

Аддитивная таблица `task_draft` не меняет историю, настройки, проекты и checkpoints. CAS выполняется под `BEGIN IMMEDIATE` и удерживает revision после удаления, защищая от ABA. Черновик — локальный буфер текста, не автоматический запрос модели; пользовательский текст сохраняется буквально. Как любой локальный текст задачи, он может содержать чувствительные сведения, поэтому профиль приложения следует защищать средствами ОС.

Защита same-origin, проверка Host, JSON mutation, permission model и подтверждение полного доступа сохранены. Палитра использует textContent и не исполняет текст задач. Reconnect повторяет только чтение. Нет новых платных сервисов, обязательных ключей или облачной индексации. Независимое ревью новых drafts/refresh не выявило P0/P1.

Ручная приёмка владельцем на Windows остаётся обязательной перед заявлением о готовности стабильного релиза:

1. Установить Setup в обычный профиль, проверить WebView2 и запуск из меню «Пуск».
2. Ввести длинную русскую задачу, дождаться «Черновик сохранён», закрыть/открыть приложение, явно восстановить. Проверить проект, набор и уровень доступа. Не считать ещё не сохранённый ввод долговечным.
3. Открыть второе окно, изменить черновик в обоих: конфликт не должен молча терять текст.
4. Ctrl+K, стрелки, Enter, Escape; открыть проект/запуск и вернуться к форме.
5. RU/EN, темы, DPI 100/125/150/175%, длинные пути; tray, уведомления, shutdown/restart.
6. Войти официальным Codex, выполнить небольшую задачу; отдельно проверить pause/resume/stop, смену доступа и наблюдаемый budget usage.
7. Проверить «Обновить.cmd», portable с сохранением профиля; QA Docker только с доверенным локальным образом и явным подтверждением.

Не проверены в облаке: интерактивный WebView2, реальный Windows DPI, вход/живое выполнение Codex и opt-in Docker. Бинарники не подписаны сертификатом. Релиз обозначается prerelease.
