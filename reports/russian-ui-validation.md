# Проверка русского интерфейса

Изменены пользовательские подписи, сообщения об ошибках, уведомления и настольные диалоги. Сохранённые идентификаторы, ключи API, статусы протокола, режимы, решения о разрешениях и названия пользовательских агентов не переименованы. Исходные диагностические данные остаются доступными в раскрываемом блоке «Технические данные»; основные действия и ошибки показаны по-русски.

## Автоматические проверки

- Backend: `python -m pytest tests/test_server.py tests/test_actions.py tests/test_desktop.py tests/test_desktop_services.py -q` — **100 passed, 1 skipped**, 5.20 с.
- Новые регрессионные проверки: `python -m pytest tests/test_russian_backend.py -q` — **9 passed**, 2.04 с. Проверены русские сообщения, неизменные категории разрешений, сохранение пользовательского идентификатора роли, стартовое окно и отсутствие отражения входных данных в ответе валидации.
- Первый DOM-аудит: **15 экранов**, Purple Neon, 1366×768; нет необработанных ошибок JavaScript, горизонтального переполнения или запрещённых английских терминов в основных видимых подписях.

DOM-аудит проверяет кнопки, заголовки, подписи полей, варианты выбора, статусы и бейджи. Технические `pre/code`, редактируемые значения и содержимое проектов не считаются текстами приложения. Это целевая регрессионная проверка, а не доказательство перевода любого возможного сообщения стороннего инструмента.

## Ограничения

Проверки браузера используют явно обозначенные HTTP fixtures и не вызывают Codex. Нативные Windows WebView2, системный трей, масштабирование Windows и установленная/переносимая сборки не запускались в Linux. Переведённые настольные диалоги проверены по коду и автоматическим тестам; требуется ручная приёмка на Windows. Нативная приёмка остаётся за владельцем; эти проверки не заменяют её и не объявляют Windows-поведение подтверждённым.

## Итоговая проверка

Полный Python-прогон: **500 passed, 9 failed, 4 skipped**, 98.25 с (`/tmp/codex-ru-final-pytest.log`). Девять падений относятся к ранее подтверждённым проверкам `tests/test_runtimes.py`; они воспроизводились на исходной ветке. Результат не объявляется полностью зелёным.

Команда браузерной матрицы:

```bash
QA_OUTPUT=/workspace/codex-russian-ui-evidence NODE_PATH=/tmp/codex-browser-tools/node_modules node tests/v21_browser.cjs after
```

**496 проверок прошли**: 450 сочетаний экранов/тем/размеров, 45 проверок CSS-масштаба 125/150/175%, один контроль видимого клавиатурного фокуса. Проверены 15 представлений, пять тем, шесть размеров от 1024×768 до 2560×1440. Не обнаружены ошибки JavaScript, неизвестные fixture-endpoints или горизонтальное переполнение. Дополнительно пройдены сохранение черновика при переходах, блокировка во время медленного запроса, ошибки доступа и повтор, отмена подготовки с ИИ и сохранение редактора, диагностика QA без выполнения инструментов и предпросмотр хранения без доступных кандидатов очистки.

Отдельный финальный DOM-аудит `node tests/v21_browser.cjs audit`: **15 экранов**, запрещённые английские термины в проверяемых основных подписях не обнаружены. Метаданные всех четырёх встроенных наборов прочитаны из актуальных JSON, проверены отображаемые роли всех 17 стандартных агентов. Инструкции модели представлены явно техническим fixture-текстом и не переводятся как данные приложения.

Отдельный `node tests/v21_browser.cjs privacy` проверил актуальную форму ответа API: русское `detail` плюс `validation_errors`. Основной текст поля — «Проект: Заполните обязательное поле.»; значение `input` не появляется в DOM, включая технический блок. Модельных вызовов не выполнялось.
