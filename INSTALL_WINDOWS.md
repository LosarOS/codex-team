# Установка Codex Team в Windows

Поддерживаются **Windows 10 x64, сборка 19041 или новее, и Windows 11 x64**. Для входа и работы Codex требуется интернет. Python, официальный Codex и переносимый Git входят в комплект; вручную устанавливать их не нужно. Зависимости конкретного рабочего проекта устанавливаются отдельно.

## Обычная установка

1. Скачайте установочный ZIP из раздела **Releases** репозитория. Распакуйте его целиком.
2. Запустите `CodexTeam-Setup-x64.exe`. Если рядом опубликованы контрольные суммы, сверяйте SHA-256 с файлом из того же выпуска.
3. Пройдите русский мастер установки. По умолчанию программа устанавливается только для текущего пользователя в `%LOCALAPPDATA%\Programs\CodexTeam`; права администратора для самого приложения не требуются.
4. Если нет **Microsoft Edge WebView2 Runtime**, мастер запросит согласие на запуск включённого установщика Microsoft. Для загрузки Runtime нужен интернет. Сам Runtime может запросить дополнительные разрешения. При отказе установка Codex Team не продолжается.
5. Запустите приложение через ярлык на рабочем столе или меню «Пуск». Памятка `НАЧАЛО.txt` находится рядом с программой.

Установщик самого Codex Team может быть без цифровой подписи. В этом случае Windows может показать предупреждение о неизвестном издателе. Проверяйте источник выпуска и контрольную сумму; отсутствие предупреждения SmartScreen не гарантируется. Включённый загрузчик WebView2 проверяется сборкой на действительную подпись Microsoft.

## Первый запуск

1. Подключите аккаунт через официальный вход ChatGPT / Codex. API-ключ для основного способа подключения не нужен.
2. Добавьте локальный Git-проект в разделе «Проекты».
3. Сохраните незакоммиченные изменения перед созданием изолированной рабочей копии.
4. Подготовьте задачу, проверьте режим, разрешения и бюджет, затем запустите команду.

Встроенный Git доступен только процессу приложения. Установщик не меняет системную переменную `PATH` и не удаляет установленный пользователем Git.

**Проверка качества** использует локальный Docker в режиме Linux-контейнеров и подготовленный доверенный образ. Docker не входит в комплект; его установка и скачивание образов не выполняются автоматически. Это отдельная настройка, а не условие установки основного приложения.

OpenAI API остаётся необязательным способом подключения с отдельной оплатой и собственным ключом. Приложение не переключается на него автоматически. Подробнее: [Способы подключения](docs/PROVIDERS.md).

## Данные и обновление

- Программа: `%LOCALAPPDATA%\Programs\CodexTeam`.
- История, настройки и данные обычной установки: `%LOCALAPPDATA%\CodexTeam`.
- `CODEX_TEAM_DATA_ROOT`, если задана явно, переопределяет каталог данных.

Перед обновлением завершите или приостановите запуск и полностью закройте приложение. Установите новую версию поверх прежней: постоянный идентификатор установщика сохраняет существующую установку. Перед обновлением сделайте резервную копию папки данных при закрытом приложении.

Удаление через настройки Windows или меню «Пуск» удаляет программу, **сохраняя пользовательские данные, рабочие проекты и авторизацию Codex**. Для очистки этих данных требуется отдельное осознанное действие владельца.

## Переносимая версия

Используйте отдельный архив `CodexTeam-Portable-x64.zip`. Распакуйте **весь архив** в доступную для записи папку и запустите `CodexTeam.exe`. Запуск одного EXE без `_internal` не поддерживается.

Маркер `portable.json` выбирает папку `data` рядом с программой. В обычной установке этого маркера нет. Не распаковывайте переносимую версию поверх установленной. История обычного и переносимого вариантов автоматически не объединяется: при смене варианта сначала проверьте выбранный каталог данных.

## Тихая установка

Тихая установка требует заранее установленного WebView2. Она не запрашивает согласие и не загружает Runtime автоматически.

```powershell
.\CodexTeam-Setup-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TASKS=desktopicon
& "$env:LOCALAPPDATA\Programs\CodexTeam\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

Наличие собранных файлов и успешные автоматические проверки не заменяют приёмку владельцем на Windows: проверьте установку, вход, запуск задачи, обновление, удаление с сохранением истории и отдельный запуск переносимой версии.
