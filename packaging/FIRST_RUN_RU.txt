CODEX TEAM — ПЕРВЫЙ ЗАПУСК

СКАЧАЛИ АРХИВ С УСТАНОВЩИКОМ?

Если файл называется CodexTeam-Setup-x64.zip, распакуйте архив целиком и запустите CodexTeam-Setup-x64.exe. Пройдите мастер установки, затем откройте программу через появившийся ярлык.

Если вы выбрали CodexTeam-Portable-x64.zip, установщик не нужен: порядок запуска описан ниже в разделе «Переносимая версия».

1. Откройте Codex Team через ярлык на рабочем столе или в меню «Пуск».
2. Подключите аккаунт через официальный вход ChatGPT / Codex. Отдельный API-ключ для этого способа подключения не нужен.
3. В разделе «Проекты» выберите папку своего Git-репозитория.
4. Опишите задачу на странице «Обзор» или подготовьте задание в «Архитекторе задач».
5. Перед запуском проверьте режим работы, разрешения и ограничения бюджета. Решения по запросам доступа доступны в «Центре действий».

ЧТО ВКЛЮЧЕНО

Python, официальный Codex и переносимый Git входят в комплект. Устанавливать их отдельно и менять системную переменную PATH не требуется. Зависимости вашего проекта устанавливаются отдельно.

Для окна приложения необходим Microsoft Edge WebView2 Runtime. Если он отсутствует, установщик Codex Team предложит запустить официальный установщик Microsoft. Для загрузки Runtime потребуется интернет и ваше подтверждение.

ОБЫЧНАЯ УСТАНОВКА

Приложение: %LOCALAPPDATA%\Programs\CodexTeam
История, настройки и данные: %LOCALAPPDATA%\CodexTeam

Закройте Codex Team перед обновлением. Установите новую версию поверх прежней. Удаление приложения сохраняет историю, настройки, проекты и авторизацию Codex. Перед обновлением рекомендуется сделать резервную копию папки данных при закрытом приложении.

ПЕРЕНОСИМАЯ ВЕРСИЯ

Распакуйте весь ZIP-архив в папку, в которую у вас есть право записи, и запустите CodexTeam.exe. Не переносите EXE отдельно от папки _internal и остальных файлов. Маркер portable.json выбирает папку data рядом с программой. Не распаковывайте переносимую версию поверх обычной установки.

Если переменная CODEX_TEAM_DATA_ROOT задана явно, используется указанный в ней каталог данных. При переходе между обычной и переносимой версией их папки данных автоматически не объединяются.

ЕСЛИ НЕ УДАЁТСЯ НАЧАТЬ РАБОТУ

Проверьте подключение к интернету и официальный вход Codex. Для изолированной рабочей копии нужен чистый Git-репозиторий: сохраните незакоммиченные изменения в своём Git-инструменте. В настройках приложения доступны состояние компонентов и диагностика.

Независимая проверка качества использует отдельный локальный Docker с Linux-контейнерами. Docker и образы не входят в комплект и не устанавливаются автоматически. Остальные функции приложения не требуют Docker.

OpenAI API — отдельный необязательный способ подключения с собственной оплатой. Он не включается автоматически при достижении лимита Codex.

ОБНОВЛЕНИЯ

Закройте Codex Team и запустите Обновить.cmd рядом с программой. Файл проверяет выпуски GitHub и контрольные суммы. В обычной версии запускается мастер установки; в переносимой обновляются файлы программы с резервной копией, а папка data сохраняется. Не запускайте несколько обновлений одновременно.
